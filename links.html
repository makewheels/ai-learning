外挂记忆层(向量 / 语义检索那一路)

两家原生记忆都不用向量库;下面这些是「补上语义检索 / 跨机器 / 跨工具」的第三方层,常被拿来和原生方案对比或叠加。

  • Mem0 — 托管 + 开源记忆层;对 Codex 提供 MCP 集成(add_memory/search_memories 等),跨机器跨工具。
  • Honcho(plastic-labs) — 辩证式用户建模;Hermes 默认外接的用户画像层。
  • Hindsight(Vectorize) — 给 Codex 加跨会话持久召回的方案与博客。
  • Cognee — 以 MCP 服务器形式给 Codex 加跨会话记忆。
  • MemoryRouter — 生命周期 hook(每轮捕获 + 召回)+ 跨工具 vault;和 Codex 原生 Memories 的分工讲得清楚。
